# v1.29.0 — Light theme + match system (lightweight spec)

Claude Code note documenting the two real decisions. No data model change — this
extends the existing v1.11.0 token system with a third palette plus an OS-aware
preference layer.

## Decisions

1. **System is the new default.** A fresh user (no `mtg-theme` key) follows the
   OS instead of being pinned to Warm Stone. Rationale: requested explicitly
   ("match the system by default"). Migration impact: existing Warm-Stone users
   (no stored key) move to System — they stay on Warm Stone on a dark OS, and
   shift to Light on a light OS. Users who explicitly picked Zed Dark
   (`mtg-theme: "zed-dark"`) are unaffected.

2. **System-dark resolves to Warm Stone, not Zed Dark.** Per direction, the warm
   dark is the canonical dark. Zed Dark remains available only as an explicit
   pick. So: light OS → Light, dark OS → Warm Stone.

## Architecture

- **Preference vs. resolved theme** split in `src/lib/theme.ts`:
  - Preference (`ThemePreference`): `system | warm-stone | zed-dark | light`,
    stored in `mtg-theme` (`system` = key absent).
  - Resolved (`ResolvedTheme`): `warm-stone | zed-dark | light`, painted via the
    `<html>` `data-theme` attribute (Warm Stone = no attribute, the `:root`
    default).
  - `resolveTheme()` consults `(prefers-color-scheme: dark)` in JS for `system`.
- **No-flash init** (`layout.tsx`) inlines an equivalent resolver (must run
  before modules load) + a `matchMedia` listener that repaints live while the
  preference is `system`. Keep it in sync with `theme.ts`.
- The dead `@media (prefers-color-scheme: dark)` block in `globals.css` (which
  only re-declared the Warm Stone defaults) was removed — resolution is JS-driven.

## Light palette

`[data-theme="light"]` in `globals.css`, filling the full 25-token contract.
Warm-light direction (daylight counterpart to Warm Stone): warm off-white
surfaces (`#faf7f2` base), white elevated overlays/inputs, near-black warm text
(`#2a2521`), copper focus accent (`#a0725c`) shared with Warm Stone.

## UI

`SettingsView` theme picker → four swatches from `THEME_OPTIONS`
(System, Warm Stone, Zed Dark, Light). The System swatch is a split light/dark
gradient; while System is selected a caption shows which palette it resolves to.
